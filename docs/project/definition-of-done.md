# Definition of Done

A feature is done only when:
- Product acceptance criteria are approved and mapped to API, data and tests.
- Authorization and tenant scoping are enforced server-side.
- Input validation and safe error responses are implemented.
- Relevant audit events and privacy/retention behavior are documented.
- Unit, integration and critical E2E tests pass.
- Localization and accessibility are reviewed for user-facing flows.
- Metrics/logs/alerts exist for operationally important behavior without logging PII.
- Failure and retry behavior is documented and tested.
- Migration and rollback/forward-fix approach is reviewed.
- Runbook and support implications are recorded.
- Staging validation is complete and product owner signs off.
